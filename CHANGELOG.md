# Changelog

## 0.1.0 — initial experimental distribution

- Public project name: HearSwift. App, installer, executable and release assets use the new name.
- Document the accessibility origin, profile-switching mechanism, supported scope and tradeoffs in English.
- Preserve prototype settings and prevent duplicate listeners during migration.

- Tray application requests the headset call profile by opening its microphone without saving or transmitting audio.
- Toggle, spoken status and off-only global shortcuts; F11 keeps the listener alive.
- Turkish/English settings, microphone selection, configurable shortcuts and speech feedback.
- Per-user installation, logon startup, restart monitoring, Start menu and Installed Apps integration.
- Portable ZIP, source, SHA-256 checksums, CI builds and draft GitHub Releases.
- No code signing configured. Initial device coverage: AirPods 3 on Windows 11 25H2.
